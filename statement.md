## Problem Statement

The **Royal Cafe Management System** is a Python-based application developed to manage basic cafe operations. The system allows users to view cafe information, check the available menu, place orders, and generate the final bill.

The main objective of this project is to create a simple and user-friendly program while applying fundamental Python programming concepts.

---

## Objectives

The objectives of this project are:

1. To create a simple cafe management application using Python.
2. To display cafe information and menu items.
3. To allow customers to place orders and specify quantities.
4. To calculate the total bill automatically.
5. To handle invalid user inputs using exception handling.
6. To demonstrate the practical use of Python data structures and programming concepts.

---

## Expected Outcome

The program provides a simple interface through which a user can:

* View cafe details
* View the menu
* Place one or more orders
* Enter quantities
* Generate a complete bill
* Exit the application

The system calculates the price of each ordered item and displays the final total amount.

The **Royal Cafe Management System** demonstrates how basic Python programming concepts can be combined to develop a practical real-world application. The project provides hands-on experience with data structures, functions, loops, conditions, input handling, and exception handling.
